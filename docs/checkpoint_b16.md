# B16 检查点口径勘误决策文档（R6 防线）

日期：2026-09-16 17:00（Day 2）；触发：T2.0.1 自动化落地时发现
预注册触发条件的口径歧义。

## 问题

预注册文本（spec §3.5-7 / T2.0.2）写"frozen 相对最强传统基线的
增益中位数 <2% 且 BH 校正后无显著格"，但未定义"中位数"的计算
总体。两个读法产生相反判定：

| 口径 | 中位数 | 判定 |
|---|---|---|
| (a) 每任务最佳模型（random 侧） | +0.154 | 不触发（B15 原决策） |
| (b) 全格池（模型×任务×切分，n=18） | -0.024 | 字面触发 |

## 分析

- (b) 的负增益集中于两类格：**家族切分格**（LGBM 按构造免疫家族
  泄漏，frozen 落后恰是 C4 主结论的证据载体）与**弱模型/跨域模型
  格**（SpliceBERT/RNA-Sc 在 ncRNA 上不敌 k-mer——模型选择问题）。
  两类都不是 R6 想防的"预训练整体无收益"方向性错误。
- R6 的原意（红队报告原文）："万一 frozen 列显示'预训练毫无
  收益'，LoRA/full FT 列的全部前提都变了"——即问的是**预训练在
  本项目任务上是否有兑现价值的模型**。口径 (a)（每任务最佳模型）
  正是该问题。
- 附带发现：触发条件第二支"BH 校正后无任何格显著"在 3 种子
  符号检验协议下**恒真**（min p=0.25 > 任何常规 α）——预注册
  文本未预见功效墙，该支实际不可满足，属预注册缺陷，记入论文
  limitation。

## 决策

1. **主口径固定为 (a)**，辅口径 (b) 同报不判触发；自动报告
   `rnafteval.checkpoint_report`（status/checkpoint_report.md）
   按双口径输出，本文件固化该解释。
2. **不触发方案复审**：与 B15 决策一致，继续 E1 矩阵补齐。
   (b) 的负值分布本身入 C4 分析素材（frozen vs LGBM 在家族
   切分下的分化）。
3. 预注册缺陷（第二支不可满足 + 口径未定义）记入 preprint
   Limitations；后续检查点（矩阵 100% / Day 7）由自动报告执行，
   不再手动计算。
