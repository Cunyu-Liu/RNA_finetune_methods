- `status/status_tables_figs/` 是旧集群导出快照，不是当前 GPU ledger 的实时替代物。

- 当前 `valplateau_v1` 使用训练损失，不能当 validation 收敛。新实验须通过 `_valplateau_v2`、ledger+result、tokenizer/CUDA 和 validation 曲线门禁。
- 任何旧 `done` 行、PPT 内数字或单独 `result.json` 不自动等于最终科学完成；缺模型、缺 split、缺种子、pending 和失败都明确标记，不补零、不插值。

- 旧状态快照和已合并增量保存在 `archive_20261026/`，没有删除实验证据。历史快照仅用于追溯，不作为当前结果入口。
